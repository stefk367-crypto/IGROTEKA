# 🎮 ІГРОТЕКА (KOINZAL)

Ігровий портал з міні-іграми, єдиною валютою (монети), магазином тем оформлення та системою досягнень. Прогрес синхронізується між пристроями через вхід Google / GitHub (Supabase).

## Можливості

- 🕹 Набір міні-ігор на спільному рушії (`engine.js`): фіксований game loop, синтезований звук без файлів, частинки, шейк камери
- 🪙 Єдиний гаманець монет для всього порталу
- 🎨 Магазин тем оформлення — куплена тема застосовується сайтом-широко
- 🏆 Досягнення, що рахуються автоматично з наявної статистики
- 📅 Щоденний бонус із бонусом за серію заходів
- ☁️ Синхронізація прогресу між пристроями (Supabase + вхід через Google/GitHub)

## Технології

- Чистий HTML / CSS / JavaScript (без фреймворків і збірки)
- Python (`main.py`) — локальний сервер для запуску без встановлення додаткових залежностей
- [Supabase](https://supabase.com) — авторизація та зберігання прогресу

## Запуск локально

```bash
python main.py
```

Сервер підніметься на `http://localhost:8000` і сам відкриє `index.html` у браузері.

## Синхронізація прогресу (опційно)

Щоб увімкнути вхід і синхронізацію між пристроями:

1. Створи проєкт на [supabase.com](https://supabase.com)
2. Виконай `supabase-schema.sql` у SQL Editor
3. Увімкни Google та GitHub провайдери в Authentication → Providers
4. Впиши свої ключі у `config.js`
5. Підключи `supabase-js`, `config.js` та `supabase-sync.js` на кожній сторінці перед `engine.js`

Без налаштованого Supabase сайт продовжує працювати повністю офлайн — прогрес зберігається в `localStorage` браузера.

## Структура проєкту

```
index.html        — головна сторінка (полиця з іграми)
shop.html         — магазин тем
achievements.html — досягнення
settings.html      — налаштування, статистика, скидання прогресу
engine.js          — спільний рушій усіх ігор
supabase-sync.js   — синхронізація прогресу (опційно)
style.css          — стилі порталу
main.py            — локальний сервер запуску
```
